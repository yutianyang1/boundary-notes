# 好友、私聊与站内公告

登录并完成账号验证后，公共站点和管理后台右下角会出现好友消息入口。

- 在“好友”中按注册邮箱或昵称精确搜索。好友申请需要对方接受；双方互相申请时自动成为好友。
- 成为好友后可以发起一对一私聊。会话和消息保存在 PostgreSQL；打开会话时标记已读，页面每 3 秒刷新消息，每 8 秒刷新好友、申请和未读数。
- “公告”显示发给当前账号的管理员群发消息。管理员在“群发”页发送后，系统为当时所有有效账号建立收件记录；之后新注册账号不会收到旧公告。
- 未读徽标合并好友申请、私聊和站内公告数量。退出登录、账号被停用或删除后不会继续提供社交 API。
- 私聊与群发文本最多 4000 字符；好友申请和聊天发送有用户级频率限制。群发操作写入管理员审计日志，日志不包含消息正文。

功能路由统一位于 `/api/social`；管理员群发路由位于 `/api/admin/social/announcements`。数据库变更由 Drizzle 迁移管理。
