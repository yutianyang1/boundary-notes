边界笔记 · 精修对比 · 2026-09-14

风格不换，只把细节做到位

左边是线上现在的样子，右边是在同一个真实页面上叠加精修样式后的截图，内容、布局、配色体系都没变。 改动分成 6 处，可以整体要，也可以只挑其中几条告诉我编号。

  • P1首屏有氛围

    留白收紧，第一屏能看到完整的头条。标题背后加一层很淡的品牌光和细网格，「边界」两个字带一道暖色底痕，和关于页呼应。

  • P2登录按钮让位

    之前是整页最显眼的实心蓝按钮，改成描边按钮。读者来看文章，不是来登录的。

  • P3区块标题统一

    「最新文章」和「热门文章」原来是两套写法，现在字号字重一致；区块上方的分隔线从 2px 减到 1px，不再像报纸栏线。

  • P4卡片更舒展

    内边距加大，静止时有一丝层次，悬停时带淡淡的品牌色投影；日期从「08-27」改成「8月27日」。

  • P5封面去廉价感

    加一层细颗粒和斜向微光，同心弧和等高线的细线做了抗锯齿，减少断续的锯齿纹。

  • P6代码块配色

    暗色下代码块原来是 GitHub 那种灰，和靛黑的站点底色不搭，改成跟随站点底色。

截图方式：用无头浏览器打开线上 xiudou.site，先截一张，再在同一页面上注入精修样式截第二张。没有改线上代码，也没有部署。
